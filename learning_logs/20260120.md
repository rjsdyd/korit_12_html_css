### font-style
1. italic : 글자를 기울인 서체로 쓴 것
2. oblique : 기존 글자에 각도를 넣어 기울인 것

### font-weight
굵기를 바꾸려면 font-weight 속성을 이용, 원래 굵기를 위한 값은 normal,
굵게 하려면 bold를 사용, 마찬가지로 서체마다 normal / bold의 보유 여부가 다르고,
심지어 100~900 사이의 숫자로 가중치를 두어 굵게를 미세하게 조정 가능

## 기본 너비와 개념
https://showcases.yalco.kr/html-css/02-05/01.html
어제 배웠던 대로라면 `<span>` vs `<div>`의 성격상의 차이로, span 태그는 내부 요소의 컨텐츠 길이만큼의 영역을 차지하고, div 태그는 컨텐츠 영역이 차지하는 행 전체의 영역

그런데 그건 HTML 상에서의 태그 성격일뿐, CSS로는 그것을 반전 가능
display 속성을 이용

displat 속성의 속성 값
  1. inline : 컨텐츠 길이의 영역만큼만 차지하게끔 설정
    - 너비를 인위적으로 설정하는 것이 불가능 -> 컨텐츠 길이의 영역만큼 너비가 정해지기에
    - 높이도 인위적으로 설정하는 것이 불가능
  2. block : 컨텐츠 길이가 차지하는 행 전체 영역만큼 차지하게끔 설정
    - 너비 / 높이를 인위적으로 설정하는 것이 가능
  3. inline-block : 기본적으로 인라인 요소의 속성을 따릅니다. (콘첸츠 길이의 영역만큼만 차지한다는 점에서). 그러나 인위적으로 너비와 높이를 설정 가능.

## 너비와 높이 조절하기
- width : 너비 / 가로 길이
- height : 높이 / 세로 길이

## 여백 적용하기
- margin : 컨텐츠 영역의 바깥쪽 여백 - border를 기준으로 바깥쪽이기에 컨텐츠 박스 자체가 시각적으로 커져보이지는 않음.
- padding : 컨텐츠 영역의 안쪽 여백 - border를 기준으로 안쪽이기에 컨텐츠 박스 자체가 시각적으로 커져보임.

# 박스 모델
## 요소의 크기
https://showcases.yalco.kr/html-css/02-06/01.html
요소의 크기라고 했으니 기본적으로 display가 block이거나 inline-block.
고정값 크기는 보통 px 이용할건데, 브라우저나 모니터 사이즈나 모바일이냐에 따라 달라지기에 px을 사용하면 불편할것임.

이떄 상대값으로 퍼센트를 사용하면 부모 크기에 비례한 길이가 됨.
디바이스에 따라 유동적으로 크기를 조절할 때 유용한 기능이 뷰포트. 실제 창 (브라우저) 크기라고 생각할 수 있음.

뷰포트를 이용하는 단위
- vw : 뷰포트를 기준으로 가로 길이 1~100까지 있음
- vh : 뷰포트를 기준으로 세로 길이 1~100까지 있음
- vmax : 상대적으로 길이가 긴 쪽
- vmin : 상대적으로 길이가 짧은 쪽
  - vmax / vmin의 경우 어떤 디바이스를 쓰는가에 따라 다른데... 일반적인 PC / RapTop의 경우 vmax는 가로길이겠지만 모바일 폰의 경우에는 세로 길이에 해당한다는 차이점.

vw / vh의 경우에는 텍스트 크기를 설정하는 데에도 사용 가능. 예를 들어 font-size 속성을 10vmin으로 지정한다면 어떤 화면에서 길이가 짧은 쪽의 1/10 정도의 크기를 설정한다고 할 수 있음.

이상과 같이 화면 크기에 따라 텍스트의 크기가 동적으로 변해야 할 때는 font-size를 v 단위로 사용하는 방법도 있음.

텍스트를 영역의 중간에 위치하는 방법
```css
div {
  background-color: blue;
  text-align: center;
  height: 100vh;
  line-height: 100vh;
  /* height와 line-height를 동일한 값을 주게 되면 '텍스트가 한줄일 경우' 중간에 위치시킬 수 있음. */
}
```

또 다른 크기를 조절하는 방법은 복잡한 계산을 PC에게 넘기는 방식. 매개 변수를 이용해
css에서 특정한 수치를 계산해주는 함수인 calc()를 이용

예를 들어, calc(100% + 100px)이라고 하면 상대값 100%의 수치에 100px 더 큰값으로 나타내도록 합니다.
그래서 절대값 뿐만 아니라 상대값, 그리고 vw, vh 등을 매개변수로 사용할 수 있음.

## margin vs padding

### margin & padding
1. margin 값을 하나로 지정하는 경우 : 상하좌우 모든 방향에 마진 적용
2. 두 개로 지정하는 경우 : 상하 / 좌우
3. 네 개로 지정하는 경우 : 상우하좌 순서대로 적용 (12시부터 시계방향)
4. 세 개로 지정하는 경우 : 상 / 좌우 / 하로 적용됨.

근데 margin-top / padding-bottom 등 하나하나를 속성으로 지정해줄 수도 있음.

* 주의사항
블록 요소의 위, 아래 margin은 전후 블록 요소의 것과 상쇄됩니다.
그런데 문제는, 왠만하면 전후의 상하 margin이 동일한 값이면 별로 상관이 없는데 혹시나 
div-1의 마진 상하가 30px이고, div-2의 마진 상하가 60px이면, 30px은 무시되고 60px로 결정나게 됨.

혹시나 직접 지정하지 않은 여백이 있는 경우
(특히 live server를 켰을 때)는 브라우저 자체에서 여백을 지원하기에

개발자 도구 상에서 margin = 0로 고쳐주면 좀 더 의도한 화면이 나옴.
